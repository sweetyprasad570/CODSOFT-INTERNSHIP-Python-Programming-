## 🔐 Password Generator

A colorful, animated, and user-friendly Python Tkinter Password Generator that creates secure passwords of varying strength, with features to save, copy, and view passwords — plus a light/dark theme toggle for style lovers 🌈✨

## ✨ Features

✅ Generate passwords with different strength levels — Easy, Medium, Strong

✅ Copy password directly to clipboard

✅ Save password to my_password.txt file

✅ View saved passwords in a popup window

✅ Light 🌞 and Dark 🌙 theme toggle

✅ Animated colorful title and smooth text effects

✅ Hover button color transitions

✅ Error handling for invalid inputs

## ⚙️ How to Run

1️⃣ Make sure Python 3.x is installed on your system

2️⃣ Copy this code into a file named password_generator.py

3️⃣ Open Command Prompt or Terminal

4️⃣ Navigate to the file’s location and run the command:

python password_generator.py


5️⃣ Enjoy your colorful password generator 🎨🔐

## 🧠 Password Strength Options
| **Option** | **Includes**               | **Example**  |
| ---------- | -------------------------- | ------------ |
| Easy       | Lowercase letters only     | `xjvprtkh`   |
| Medium     | Letters + digits           | `G2bYq7Ls`   |
| Strong     | Letters + digits + symbols | `X7$pT@2!zQ` |


## 🔘 Button Functions
| **Button**        | **Function / Use**                         |
| ----------------- | ------------------------------------------ |
| Generate Password | Creates a new password                     |
| Regenerate        | Generates a new password again             |
| Save Password     | Saves password to `my_password.txt`        |
| View Saved        | Displays saved password(s)                 |
| Copy Password     | Copies password to clipboard               |
| Toggle Theme      | Switch between Light 🌞 and Dark 🌙 themes |
